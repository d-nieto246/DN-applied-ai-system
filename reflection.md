# Personal Reflection

Building PawPal+ shifted how I think about what it means to use AI in a real system. Before this project, I thought of AI as something you prompt and get an answer from — a smarter search box. What changed was implementing the agentic loop: watching Claude not just generate a schedule, but call a tool, read the result, detect that it created a conflict, and fix it without being told to. That loop — plan, act, check, fix — is the thing I'll carry forward. It's the difference between a language model that produces text and an agent that does work.

The part that surprised me most was how much the quality of the tools mattered. Claude's planning was never the bottleneck. The hard work was designing the five tool interfaces so their inputs and outputs were clear enough for the model to use reliably — getting datetime formats right, writing error messages that gave Claude enough information to self-correct, deciding which operations deserved a separate tool versus being collapsed into one. The AI was easy. The interfaces were the engineering.

This project also made the responsibility side of AI concrete for me. The agent speaks confidently in fluent prose, which can make a first-time pet owner trust it more than they should. The system has no knowledge of a specific animal's health history, medications, or individual needs — it works from patterns in training data, not veterinary expertise. Knowing that, and knowing the schedule has no undo button, made me take the guardrails seriously rather than treating them as a checkbox. Reliability isn't just about whether the code runs — it's about whether the person using it can trust the output enough to act on it safely.
